# AXESS — brand files

Mark: the "cut A" (option 4a). A solid A whose crossbar stops short of the right leg — the gap reads as a way in.

## Colors
| Role | Hex |
|---|---|
| Ink (primary) | #0E1013 |
| Paper | #F7F6F3 |
| Deep green (accent) | #1D5A4A |
| Mint (digital accent, dark bg only) | #35A07F |
| Grey text | #6A6862 (light bg) / #8B8F96 (dark bg) |
| Redaction bar | #3A4048 |

## Type
- Wordmark + headlines: **Archivo**, weight 900, letter-spacing ~+0.04em (Google Fonts).
- Descriptor / labels / UI meta: **IBM Plex Mono**, weight 500, letter-spacing ~+0.2em, always uppercase.

## Descriptor
Always `A REAL ESTATE NETWORK` — uppercase, mono, never in sentence case. Never "brokerage".

## Files
- `logo/axess-mark-*.svg` — mark alone (ink, white, green) + solid tiles.
- `logo/axess-lockup-horizontal-*.svg` — primary lockup. Use above 160px wide.
- `logo/axess-lockup-stacked-*.svg` — centered use: apparel, signage, letterhead.
- `logo/axess-wordmark-*.svg` — wordmark only, when the mark appears elsewhere on the page.
- `favicon/` — 32, 64, 180 (Apple touch), 512 (PWA/maskable-safe).
- `social/` — 1000×1000 avatars, ink and green.

## Rules
- **Clear space:** one crossbar height on all sides of the mark; for lockups, the cap height of AXESS.
- **Minimum sizes:** mark 16px; horizontal lockup 140px wide; stacked lockup 90px wide.
- Only these color pairs: ink on paper, white on ink, white on green. No gradients, no shadows, no outline versions.
- Never re-space, re-weight, or re-draw the wordmark; never stretch the mark; never rotate it.
- Apparel: one-color only — white on dark garments, ink on light. Stacked lockup for chest/back, mark alone for caps and sleeves.

## Note on the SVG lockups
Lockup and wordmark SVGs reference Archivo and IBM Plex Mono as live text so you can restyle them. Before sending to a printer or embroiderer, open in Illustrator/Figma and outline the text (Type → Create Outlines) so it renders without the fonts installed.
