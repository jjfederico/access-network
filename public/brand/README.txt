DOORS — LOGO PACKAGE (direction 15a: slab & knob)
=================================================

COLORS
  Ink   #14140F   primary
  Bone  #EFECE4   reverse / light
  Paper #FFFDF8   page background

TYPE
  Wordmark: Archivo Medium (500), uppercase, 0.3em tracking
  Subline:  IBM Plex Mono Regular, uppercase, 0.22em tracking
  Both free from Google Fonts.

FOLDERS
  /logo      Lockups, transparent PNG. "-ink" = dark art for light backgrounds.
             "-bone" = light art for dark backgrounds. Number = pixel width.
               lockup-horizontal-*   icon + wordmark + split subline (primary)
               lockup-vertical-*     stacked, for square/centered spaces
               wordmark-rule-*       wordmark + rule + subline, no icon
               wordmark-only-*       wordmark alone
  /icon      Square app/icon tile. icon-ink = bone door on ink block.
             icon-slab-*-transparent = door slab only, no block.
  /favicon   favicon-16/32/48, apple-touch-icon-180, android-chrome-192/512
  /social    profile-1080-ink        Instagram / Facebook / LinkedIn profile pic
             profile-500-ink         smaller profile upload
             instagram-post-1080     square post card
             facebook-cover-1640x664
             linkedin-banner-1584x396
             x-header-1500x500
             og-image-1200x630       link preview (bone version included)
  /web       email-signature-600w, site-header-360w
  /src       full-resolution masters (4x) — keep, do not send out

RULES
  Clear space      Minimum on all sides = the height of the icon block.
  Minimum sizes    Horizontal lockup: 120px wide / 1.25in print.
                   Wordmark only: 90px wide.
                   Icon: 16px. Below 24px the knob is dropped (already done
                   in favicon-16).
  Backgrounds      Ink art on Bone/Paper only. Bone art on Ink only.
                   No logo over photography without a solid plate behind it.
  Do not           stretch, rotate, outline, add shadows, recolor, re-space the
                   letters, or set the subline in anything but Plex Mono.
  Subline          "A REAL ESTATE NETWORK". Either half may be used
                   alone when one product is the subject; keep the same
                   position it holds in the pair.

Vector (SVG/AI/EPS) files are not in this package — say the word and the
final letterforms can be drawn as vector for print and signage.
